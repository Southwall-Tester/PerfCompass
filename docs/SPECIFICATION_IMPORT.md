# 从规格摘录添加候选

在候选表下展开“从规格摘录添加候选”，填写资料来源并粘贴带字段名的文本，点击“生成规格预览”。核对具体型号、处理器、显卡和容量后添加候选；字段可修订，不明确的容量留空。报价与对应来源在候选表另填。

支持中英文的结构化字段：冒号、竖线、制表符分隔，或字段名与值分两行。它是规格表导入器，不是通用自然语言理解。CPU/GPU 名称保留为文字，不用于猜测性能；型号选项、重复但不同的记录和不明确容量会提示核对。

容量支持 GB、TB、GiB、TiB，按明确字节单位换算为候选表的十进制 GB；支持 `2x16GB` 等模块数量，不将 DDR5-4800、M.2 2242 或 PCIe 4.0x4 的数字当容量。最高支持量、可选容量、共享内存、比特单位 Gb 和传输速率不能代替已安装容量。独立显存仅从显存字段或明确的 GDDR 容量提出预览；不能由系统内存填充。

添加后，独立规格资料保留来源、本机摘录时间、用户核对后的字段和原文。摘录时间不是厂商更新时间或报价有效期。规格目标使用独立规格资料；它不充当报价依据。仅输入价格而未填报价来源时，该价格不参与预算优先、价差或节省计算。旧版的合并来源仍保持原语义，不被自动认证为独立资料。

原文和可编辑预览随比较草稿保存，容量尚未改成有效数字时也可保存草稿。修改原文或来源后禁用旧预览的添加操作，保留旧字段；“重新生成预览”明确替换下方字段。添加候选会撤销旧比较结果及覆盖确认，不自动勾选目标、生成任务测量或执行参数。

比较文件升级为 **comparison-1.4**，保留独立规格来源与摘录草稿。可以读取旧版本；旧版程序应拒绝 1.4，避免重存时静默丢弃这些资料。升级前的原始备份继续保留。模型提取、测量方法与历史格式没有因本功能改变。

本入口处理用户粘贴的资料，未实现自动商品抓取。2026-10-25 当前环境访问 Lenovo PSREF 的公开访客接口返回 403，普通规格接口也未取得数据，不能据此承诺在线导入可用。开发复核另外从[官方精确型号 83JE01DBID](https://psref.lenovo.com/Detail/LOQ_15IRX10?M=83JE01DBID)的检索摘录中手工整理少量字段，解析得到内存 16 GB、独立显存 8 GB、存储 512 GB；该型号资料示例不代表当地在售、当前报价或候选电脑实测。
