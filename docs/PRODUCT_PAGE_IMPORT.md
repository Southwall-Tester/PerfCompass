# 从商品链接添加候选

在“候选配置”点击“从商品链接添加”，填写具体商品页，读取预览后核对 SKU、CPU、GPU、容量与报价，再勾选核对并添加。添加后的资料进入现有候选草稿，不自动勾选需求条件、覆盖确认或生成任务结果。

当前允许尝试读取 Dell 中国官网和联想商城的 HTTPS 商品页。网站需要提供单一 SKU 的结构化 Product 资料；缺少资料、多个商品、登录/反爬阻止或页面结构变化时，会提示改用规格摘录。已在开发版实际入口读通 Dell `ds14260_reg_02`；不能据此承诺这些域名的所有商品页都可读取。

读取只发出指定商品页的普通 GET 请求，不发送需求或使用历史，不使用浏览器账户或 Cookie，不执行网页脚本。请求有超时、跳转和页面大小限制。网址改变、取消、失败或较早请求晚到时，旧字段可保留，但不能冒充新的读取结果添加。

只对同一页面中明确对应的固定人民币报价提出金额；多报价、起价、其他币种、缺货、过期或链接不符时，候选报价默认留空，页面原值仍保留。页面标示有货不保证当地配送或最终结算价。规格与报价来源分别保留网址、读取时间、原始 SKU 和必要摘录。

Dell 页面会列出可选配置；读取器只补充其选定 SKU 的“技术规格”，不拿所有选项里的最大内存或最高 CPU 当作该商品配置。共享内存不作为独立显存，未知字段仍可手工核对。

修改容量、CPU、GPU 或金额后，原页面报价不再充当修改后的报价来源，原金额仍可留作待补内容。修改后的低价没有来源时，不参与预算优先或价差计算。备注名称可以调整，原始 SKU 继续在资料中保留。同名候选会要求先改备注名，不丢弃当前预览。

未添加的人工编辑在普通关闭时默认返回保留；确定放弃才关闭。核对后添加的候选使用 comparison-1.4 保存，不增加文件格式或运行依赖。

开发核对使用一次真实官网请求及独立空目录中的原生窗口流程；其他异步竞态、失败和修改金额为受控输入。记录式解析夹具只保留 2026-10-25 的 SKU、Offer 和选定规格事实，另有明确标注的无关选项用于排除测试；它不代表未来报价或候选机性能。当前仍缺真实候选机器的任务收益标定。

实测来源：[Dell 14S 所选 SKU 商品页](https://www.dell.com/zh-cn/shop/laptop-computers/spd/dell14sds14260/ds14260_reg_02)。
