# 配置建议下的参考机型

主流程是监测与需求 → 配置建议 → 接近的参考产品。分析页和导出的 HTML 直接显示型号、参考配置、选择理由、官方资料来源和核对日期；不需要先填写候选、导入商品、接入商家或完成候选机实测。程序不联网读取商品页。

当前是小型本地资料表，仅包含部分笔记本。核显轻载路线先看核显机型，已观测 GPU 重任务先看独显路线，路线未知时明确列为类型示例。CPU 型号用于定位产品，不根据旧机占用率推算性能等同。未核对的新需求与软件兼容性不会因此被宣称满足。

已确认的内存、存储、独立显存标称 GB 边界用于筛选参考配置，包括严格大于/小于边界。条件分支各自筛选；容量冲突时不列“匹配产品”；库内无匹配项时明确说明，不自动放宽边界。观测可用 GiB 与商品标称 GB 分开，参考机型不是已验证可用容量或任务达标结论。
