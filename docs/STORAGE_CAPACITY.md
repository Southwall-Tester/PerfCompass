# 用固定卷占用筛选存储容量

配置分析的存储卡可展开标称容量与已取得固定卷占用的差额；HTML 使用同一数据。采用所选窗口最后一条有效性可核对的记录并显示日期，不把较早峰值当作当前迁移量；最后一条容量缺失时也不借用旧值冒充最新读数。

商品 GB/TB 按十进制字节换算为 GiB，再与历史值比较。1 TB 约为 931.32 GiB；差额未扣格式化、系统预留和未来增长，不能直接作为新盘空闲空间。遥测旧字段名不变，数值仍为 GiB，不重算历史。

占用可能包含系统、缓存和临时文件；没有取得所有卷清单，也未证明挂载不重复。表格明确以“假设保留这些卷的合计占用”为前提。购机前仍需确认实际迁移内容，不能把合计直接当作用户文件总量或必需购买容量。无效数值、缺少容量字段、历史异常和硬件未隔离时不显示对照；已知的零占用与缺失字段分开。

本功能不判断 SSD 速度或寿命，不自动创建候选条件。已有的新数据需求、空间压力与体验问题继续通过原分析显示。采集接口返回字节，见 [DriveInfo.TotalFreeSpace](https://learn.microsoft.com/en-us/dotnet/api/system.io.driveinfo.totalfreespace?view=net-10.0)；单位换算依据 [NIST 二进制前缀](https://physics.nist.gov/cuu/Units/binary.html)。
