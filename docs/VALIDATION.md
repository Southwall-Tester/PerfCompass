- Release 构建 0 警告、0 错误；65 项分析与存储回归通过，新增体验窗口裁剪、重复采样去重、场景与硬件隔离、过期数据、处理状态恢复、规则解析确认及配置建议联动。
- 首轮 WPF 流程 32 项通过，覆盖真实输入控件的解析、AI 歧义阻止保存、确认持久化、修改原文使确认失效、体验保存、历史显示、报告转义和标为已处理。已查看设置与体验页实际渲染，修复了保存成功后仍显示旧歧义提示的问题。
- `--nlp-evaluate` 执行 36 条人工编写的广度诊断用例，当前规则只有 12 条字段集合完全一致。这揭示了其在开放任务、条件、时间和数值约束上的不足，不是通用语义能力验证。源码中的规则预解析明确标为有限能力，未解析片段不参与建议。
- 查阅论文、开源方案、研究方向和诊断范围见 `NLP_RESEARCH.md`。尚未取得本项目中的语义模型准确性结论，不能将模型下载、JSON 合法或原文定位正确等同于理解正确。
- 体验记录不是自动体验测量：由用户标记症状，关联此前两分钟同场景、同硬件的近期采样。暂停或最后采样超过 6 秒时不借用旧值。采样高负载只表示同时出现，不自动判断根因。
