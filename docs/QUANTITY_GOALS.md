# 从已核对需求到量化比较

0.8.0 在模型候选核对区显示「候选比较目标」。保存选用事项后，导入候选比较即可得到可检查的目标值、方向、单位和引用。转换不改变默认未选用、用户核对和测试可比性要求。

这是一套用于已核对事实的数量语法，不是新的通用自然语言模型。陌生任务名称保持开放；软件不会从名称猜测硬件型号或性能。规则预解析仍是原来的有限基线。

## 数值与边界

| 已核对内容 | 比较目标 |
|---|---|
| 预算六千到八千，单位元 | 报价至少 6000 元，且不超过 8000 元 |
| Cubase 监听延迟低于 10 毫秒 | 实测严格小于 0.01 秒 |
| 电脑重量不超过 1500 克 | 实测不超过 1.5 kg |
| 续航至少六小时 | 实测至少 21600 秒 |
| 存储 500 GB 到 2 TB | 容量至少 500 GB，且不超过 2000 GB |
| 内存至少 32 GiB | 容量至少 34.359738368 GB |

支持明确的至少/不超过、严格大于/小于、闭区间与等于。区间与等于生成两个独立条件，均需核对；条件需求保留触发条件。过去、排除和不确定事项不被改成必需的容量下限。

数值、单位及边界方向要与所引用原文相符。模型把 64 改为 32、把不超过改为至少、把低于改成不超过、添加原文未给的容量单位时，不自动生成数值约束。单位允许同量纲的明确换算。整机预算中已核对的「元」可以在原句省略，但不将美元等外币当作人民币；不换算汇率。

「低于 10」与「不超过 10」分别保存。恰好 10 时，前者不通过，后者通过。重复耗时仍检查全部正式轮次：全部满足才通过，全部不满足才失败，部分满足则待验证。不能用中位数掩盖越界。

这些检查不能证明模型正确理解了主体、否定或完整需求。逐字引用也不证明语义正确。完整原文、遗漏、触发条件和目标仍需核对，原文或字段修改后需重新确认。

0.8.1 根据实际提供方输出，补足「延迟低于10毫秒」「至少要64GB」等对象前缀和语气助词，以及「不能低于」「不要超过」的数值关系。只接受单一、完整的边界或范围，不丢弃前缀中的否定、不确定或其他数值；引用含复杂否定/不确定时继续核对。它不是从缺失的结构化值或引述全文中猜测新需求。

## 单位与测试

容量按 GB（十进制）比较，GB/TB/MB 与 GiB/TiB/MiB 明确换算。手填配置也须核对厂商口径；本软件不会自动把商品上模糊的「32G」解释成某种容量单位。Gb 和 GB 不互换，带宽不当作存储容量。毫秒、微秒、分钟和小时可换成秒；重量换成 kg；功耗使用 W；帧率使用 FPS。dB 与 dBA 分别保留，不相互转换。当前未覆盖的单位保留逐项核对。

延迟、续航、重量、功耗、噪声和帧率进入「实际任务测量」类型，结果由用户填写并注明依据、统一步骤与环境。它们没有因此成为软件自动测得的数据。内置进程运行器只测根进程退出耗时；不能用它的运行耗时代替音频监听延迟、电池续航或完整任务正确性。

模糊的「一万五」「32 起步，64 更好」、近似量、相反或不一致的字段、组件预算、未明确的混合部件，以及从数据增长推算出的新值，继续作为完整文字核对。本轮没有实现概率容差、偏好权重、多目标最优化或硬件性能预测。

## 历史占用的二进制单位

采集器一直按 2^30 字节记录内存与卷容量，按 2^20 字节记录进程内存与读写速度。0.8 修正实时界面、场景、趋势、分析和导出中的标签为 GiB/MiB、MiB/s。没有把历史数值乘除一次，也没有重写用户历史。

旧 JSON 的 `MemoryUsedGb` 等字段名为兼容性保留，实际单位仍是 GiB；`DiskReadMbps` 为 MiB/s。新 CSV 用 `_gib`、`_mib_per_second` 表头明确单位。旧 CSV 原始数字同样是二进制量，不能仅凭旧的 `_gb` 名称把它当作十进制。内存候选档位按物理 GiB 估算，购买前核对商品标称与实际容量。

上游显存的读取参考 [LibreHardwareMonitor NVIDIA 实现](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/blob/v0.9.6/LibreHardwareMonitorLib/Hardware/Gpu/NvidiaGpu.cs)；具体硬件仍需实机验证。

## 存储版本与验证

比较文件升级为 `comparison-1.2`。新版本能读取 1.0/1.1 并保留原有核对签名；保存后旧版本会拒绝该文件，避免把严格边界误解释成其他方向。原条件与实测不会因再次导入而被直接覆盖；此前手工条件需要整理并重新核对。

`tests/quantity-cases.json` 是 40 条开发者编写的数量语法回归，不是模型理解准确率。另有严格边界、重复测量、原文不符、单位碎片、条件范围、实时预览与二进制单位的回归。原生流程使用实际输入与比较控件，模型响应与报价、测量均为合成数据。完整验证范围见 `VALIDATION.md`。
