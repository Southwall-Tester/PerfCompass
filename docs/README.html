PerfCompass 使用说明

开始记录

正常使用电脑，在右上角选择当前场景。实时概览显示当前 CPU、内存、GPU、磁盘活动，以及活跃应用。

关闭窗口后会继续在系统托盘记录。双击托盘图标恢复窗口；使用“退出程序”停止运行。

查看配置分析

至少累计 10 小时有效使用、覆盖 3 天，运行过平时的典型任务后，在记录设置中确认当前硬件配置的任务覆盖情况。旧版未绑定的确认或硬件配置改变后，需要重新勾选并保存，历史记录仍保留。展开每项建议可以查看数据依据和选型条件。

“疑似过剩”给出可评估的降档方向；“压力线索”提示需要核对任务耗时或卡顿；“证据积累中”表示继续观察。具体配置仍应在候选机器上运行实际任务验证。

近期需求变化

按场景查看最近 7/14/30/90 天。独立对照最近 7 天与此前 7 天、最近 30 天与此前 30 天；近期反复新增的重任务优先约束配置建议。缺少对照记录时继续积累，近期减少不代表过去任务永远不再需要。

冗余判断还需要最近 7 天至少 30 分钟、跨 2 天的有效观测及相关传感器证据。完整方法见 DEMAND_MODEL.md。

采集与数据

实时约 2 秒刷新，历史约 10 秒保存，新设置默认保留 90 天，可选 30/60/90 天；旧设置保持原值。纯空闲时段从配置过剩分析中排除，明显后台任务仍算有效使用。

数据位于程序旁的 data 文件夹。进程列表只实时展示。采样与进程不上传；报告和 CSV 由你主动导出。可选模型解析仅在点击发送时向所配服务发送需求描述。

硬件传感器的可用性取决于设备、驱动与权限。缺失值显示“—”，不会被当作零。传感器更新失败时，实时页显示设备与重试提示，该设备的旧读数不计入新观测，成功后自动恢复。基础 CPU 与内存采集使用 Windows API；温度等附加传感器可能不可用。

需求与体验

实时页可记录卡顿或等待，以及此前两分钟的采样线索。历史页可核对并标为已处理；同时出现高占用不能证明原因。

设置页支持有限规则预解析。逐项核对后确认保存，字段才参与配置建议；修改原文后需要重新解析。陌生任务、复杂条件、时间与数值仍可能无法识别，当前不是通用自然语言理解。研究与诊断见 docs/NLP_RESEARCH.md。

可选模型解析

在记录设置打开“模型解析与逐项核对”，配置接口后主动发送需求描述。候选默认不选用，可以修改、排除与补充，核对原文后保存才参与建议。密钥仅在当前运行保留。

条件与过去需求不作为必然的新任务；本机服务会暂停监测，请停止该服务后再继续。完整说明见 docs/MODEL_REQUIREMENTS.md；接口通过不代表模型语义质量通过。

比较候选配置

在“候选配置”添加两至三套电脑，填写报价、容量和来源，导入已确认需求与近期任务。核对目标与触发条件，再填写同一任务下的测量或兼容性核对记录。缺少依据的项目保留待验证。

确认覆盖重要和偶发任务后保存比较，可查看不足项、报价差、容量变化与已记录的任务表现，并导出 HTML。条件需求单列，修改配置或测试步骤后需重新核对。预算和容量上下界没有共同范围时，会列出冲突条件，先核对输入再比较。不同触发情景分别检查。详细流程见 docs/CANDIDATE_COMPARISON.md。

重复任务测量

选择会自行退出的程序、参数、输入文件及统一步骤，记录多次耗时，再在候选比较中导入对应任务行。保留各次范围，结果跨过目标时待验证。失败、取消、超时或协议不同不能当作更快。

程序与输入校验会影响缓存，不代表冷缓存性能；根进程退出也不证明分离后台任务已结束。测量期间暂停本实例的长期记录，结束后确认任务停止再继续。详见 docs/TASK_MEASUREMENT.md。

备份与恢复

在“记录设置 → 数据保护”保存备份。窗口打开时暂停监测，关闭后恢复此前状态。备份未加密，包含需求与任务参数，请放在可信位置。

选取备份校验后，恢复到新的独立目录；可用当前程序打开该目录，初始暂停监测和历史清理。重新启用清理前会显示过期文件数量。设置损坏时保留原件，尝试上次有效副本，并提示核对。普通设置修改不会自动解除恢复核对。

设置保存失败时，窗口上方会持续提示，需求与核对输入保留；排除文件占用、权限或空间问题后再次保存。场景失败时回到实际记录的场景。后台保存失败会尝试恢复原自启动项；无法确认时请核对 Windows 启动应用。

完整说明见 docs/DATA_PROTECTION.md。

量化目标与单位

核对模型候选时可查看量化比较目标。预算范围生成上下界，低于与不超过分别处理，毫秒、重量、续航、容量等按明确单位换算。原文数字、单位或边界不符时继续逐项核对。

内存、显存、卷容量遥测使用 GiB，进程内存用 MiB，读写速度用 MiB/s。候选规格表按 GB 比较，需核对厂商口径；旧历史数值未重算。详细说明见 docs/QUANTITY_GOALS.md。

报告用途

HTML 报告可以在浏览器打开并打印为 PDF。内存容量建议、CPU 多核余量、GPU 使用情况及未来需求会一并保留，供你比较下一台电脑。

规则版本 1.5。10 小时 / 3 天属于启发式观察门槛；GPU 利用率、CPU 占用与真实体验并非一一对应，短峰可能被采样遗漏。
