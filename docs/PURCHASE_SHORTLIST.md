# 购机建议与加价取舍

候选页点击“保存并比较”后，可展开“购机建议与加价取舍”。建议使用已有的条件核对、报价和任务结果，帮助判断先考虑哪台、加价对应什么变化；不根据型号或旧机占用推算新电脑性能。

每组首先列出通过该组条件且报价金额与来源齐全的候选，最低报价列为“预算优先”，同价并列。必需条件和各个明确的条件场景分别计算；不同场景不自动合并，条件尚未核对时也不会抹去基础条件的通过结果。

更贵的候选与本组最低报价方案比较任务目标：

| 显示结果 | 含义 |
| --- | --- |
| 尚无任务收益对照 | 本组没有任务性能目标；更多内存或更高型号不自动计作收益 |
| 已记录任务未见加价优势 | 本组各任务依据都可比较，更贵方案没有数值更好的任务；可先考虑较低报价，额外规格是否另有用途仍需确认 |
| 记录到任务优势 | 更贵方案有较好任务结果，其他可比任务没有变差；是否值得由用户的实际目标决定 |
| 加价有任务取舍 | 某些任务较好、另一些较差，不按平均值或自行设定权重给出全局胜者 |
| 加价收益待核对 | 任务依据类型不同、核对过期、协议不同或重复耗时范围重叠，不能确定整体收益 |

手填结果明确标为“手填任务值”。原始重复测量需通过现有协议和状态校验，再比较正式轮次的最小至最大耗时；区间重叠时不因中位数略快就建议加钱。范围分离仅说明这批记录数值的顺序，不是统计显著性、跨硬件标定或实际产物正确性的证明。时间目标显示为毫秒时，原始耗时范围仍明确以秒展示。

只有一台符合条件和报价要求时，不计算价差。缺少报价来源的原金额保留在原候选结果中，不进入建议排序；来源非空不等于真实性或时效认证。目标冲突、范围过期、条件未核对时撤下相应建议。修改配置或输入仍按原规则使旧核对失效。

建议与 HTML 复用同一组结构化结果，比较文件仍为 comparison-1.3。没有新增自动确认、硬件或报价数据库。建议只覆盖已核对目标；“没有记录到收益”不能直接升级为“整机过剩”。
