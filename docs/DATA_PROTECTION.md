# 备份、恢复与设置保护

0.7.0 在「记录设置 → 数据保护」提供入口。

## 保存备份

打开「备份与恢复」，选择「保存备份」。该窗口打开期间暂停本实例的监测，主窗口不可编辑；托盘也不能提前继续记录。关闭窗口后恢复此前的记录状态。测量或模型解析正在运行时需要先结束任务。

`.pcbackup` 是带清单的 ZIP，逐文件记录长度与 SHA256。包括设置及上次有效设置、采样历史、体验记录、候选比较、`measurements/` 中的测量结果和 `recovery/` 中已保留的损坏设置。损坏尾行、损坏比较文件等保留原始字节，备份成功不表示每条业务记录有效。日志、EXE、脚本、模型与其他文件不在备份范围内。

备份未加密，可能包含需求原文、任务参数以及其中的路径，保存在你选的位置，不上传。请选择当前数据目录之外的可信位置；同一磁盘的副本不能防止整盘损坏。上限为 10000 个数据文件、2 GiB 解压数据、4 MiB 清单，是当前实现边界。

保存时持有存储锁，将完整 ZIP 写入唯一临时文件，关闭压缩流后刷新到磁盘，重新读取并校验全部内容，最后才替换目标备份。取消或失败时保留已有目标。其他程序直接改写数据不受本实例存储锁控制。

## 恢复与打开

1. 选择备份，等待全文件校验完成。预览显示来源版本、时间、文件数量与体积。校验值能发现内容与清单不一致，不证明提供者身份。
2. 选择一个已存在的父目录。软件会创建唯一的新目录，不覆盖当前数据或之前的恢复目录。
3. 恢复前重新验证预览清单与全部内容；提取后再次检查文件长度与 SHA256。失败或取消时移除本次临时目录，不发布成功目录。
4. 点击「用恢复数据打开新窗口（暂停记录）」启动当前程序读取新目录；不执行备份中的命令。原实例的数据位置保持不变。

恢复目录写入 `restore-protection.json`。首次及后续打开均先暂停监测，自动清理持续暂停，避免旧备份一打开就被按 30/60/90 天策略删除。可以手动继续监测；要启用历史清理，在该恢复目录的「备份与恢复」中查看过期文件数量及文件名，确认后执行。超过分析时间窗的旧记录虽保留在磁盘，也不会因此成为当前需求证据。

恢复保留原始数据，不保证旧版本程序能理解新版本文件。恢复数据应使用当前或更新的 PerfCompass。当前不提供多个目录的合并、定时备份、加密、损坏业务记录逐条修复或云端同步。

## 设置损坏时

保存设置前先保留当前有效文件为 `settings.previous.json`，新文件写入临时文件并刷新后替换。未知设置字段随保存保留，降低旧客户端丢弃新增字段的风险。

设置无法解析时，先将其原始字节保留到 `recovery/`，再尝试上次有效设置。两份都坏时使用默认值，并取消代表性确认。程序暂停监测和自动清理，显示提示，等待核对设置。读取权限或 I/O 错误不被当作空设置；无法安全读取或保留原件时停止打开该目录。

「已核对当前设置，保存恢复结果」保存已加载的恢复值，损坏原件继续保留。若需修改需求，请先编辑并保存对应需求；不从损坏文本中猜测配置要求。

## 设置保存失败与重试

需求、逐项核对事项、后台偏好及恢复核对的保存失败会在窗口上方持续提示，不随实时采集刷新消失。需求和候选输入保留，排除文件占用、目录权限或空间问题后，可再次点击对应保存按钮。成功后只清除该操作已解决的错误；其他失败仍显示。场景切换只有保存成功才生效，失败时选择框回到实际记录的场景。

后台保存先读取原自启动项，修改并读回核对，再写设置文件。若失败，尝试恢复原值及注册表类型；发现另一程序写入了不同值时不覆盖，提示核对 Windows 启动应用。自启动状态未变化时不额外写注册表。关闭行为与保留期只有设置文件成功保存才生效。

注册表与文件之间采用失败补偿，无法构成一次原子事务，也不保证进程终止、断电或其他进程同时修改时两者总是一致。恢复核对标记若未能解除，继续保留保护状态，重试前不提示核对成功。

## 文件边界与验证范围

备份保留业务文件的原始字节，包括损坏尾行。归档哈希通过不证明历史 JSON 格式或任务覆盖完整；恢复后请查看历史异常提示，选择已核对记录的备份。CSV 只导出可读取且符合所选范围的采样，完整原件请使用备份保留。历史诊断与分析约束见 `DEMAND_MODEL.md`。

只接受指定的数据文件命名空间，拒绝绝对路径、`..`、重复路径、备用数据流、Windows 设备名、链接、目录和未知版本。数据操作拒绝含重解析点的路径，需选择普通本地目录。临时目录的删除与最终移动都验证边界。文件系统依然是本机可信环境；当前不是对拥有本机目录修改权限的恶意进程的隔离沙箱。

验证记录见 `VALIDATION.md`。测试不证明断电时绝不丢失数据，也不代替磁盘故障、超大历史和长期跨版本试用。

实现参考：[FileStream.Flush(Boolean)](https://learn.microsoft.com/en-us/dotnet/api/system.io.filestream.flush?view=net-10.0) 的磁盘刷新语义；[ZipArchiveEntry.FullName](https://learn.microsoft.com/en-us/dotnet/api/system.io.compression.ziparchiveentry.fullname?view=net-10.0) 对绝对路径与越界条目的说明。调用刷新或使用 SHA256 不等同于取得断电恢复保证。
